# Task 2 - tic-tac-toe AI

## Description
an unbeatable tic-tac-toe AI built using the minimax algorithm. the AI 
evaluates all possible future moves to always choose the optimal one

## Technologies Used
python 3
minimax algorithm

## Project Structure
Task2_tictactoe/
└── tictactoe.py
└── readme.md

## How to Run
click on the run button on python
enter numbers 1-9 to place your move on the board
