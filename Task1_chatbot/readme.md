# Task 1 - Chatbot with Rule-Based Responses

## Description
this is a simple rule based chatbot built using python It responds to user 
inputs based on predefined rules using if-elif-else statements and basic 
pattern matching keyword detection this project helps understand the 
fundamentals of natural language processing and conversation flow

## Technologies Used
python 
vs code 
git hub and git

## How It Works
the chatbot checks the user's input for specific keywords like hello, 
how are you, bye and returns an appropriate predefined response 
if no keyword matches it returns a default feedback response

## How to Run
make sure python is installed on your system
run the script: python Chatbot.py
start chatting with the bot in the terminal.
type bye to exit the conversation.

## Sample Conversation
Aap: hi
Bot: Hello! Kaise help kar sakta hoon?
Aap: how are  you
Bot: Mujhe samajh nahi aaya, phir se try karo.
Aap: how are you
Bot: Main theek hoon, aap batao!
Aap: bye
Bot: Bye! Milte hain phir.
